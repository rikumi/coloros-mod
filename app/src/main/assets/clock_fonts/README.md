# Clock fonts

Font files are unmodified and redistributed under SIL Open Font License 1.1. The corresponding licenses are included in this directory.

## Sources

- Lato Regular, Medium and Bold: extracted from [EvolutionX vendor_pixelstyle](https://github.com/Evolution-X-AOSP/vendor_pixelstyle/tree/b4fea34bd9adc692c560b6612af34658d379241d/fonts). Matching [Google Fonts family](https://fonts.google.com/specimen/Lato).
- Lato SemiBold (600): [Google Fonts source](https://github.com/google/fonts/blob/main/ofl/lato/Lato-SemiBold.ttf), retrieved 2026-10-07.
- Inter: [Google Fonts](https://fonts.google.com/specimen/Inter), [source](https://github.com/google/fonts/tree/main/ofl/inter). Variable axes: wght 100–900, opsz 14–32.
- Manrope: present in the EvolutionX font pack; packaged variable version from [Google Fonts](https://fonts.google.com/specimen/Manrope), [source](https://github.com/google/fonts/tree/main/ofl/manrope). Variable wght 200–800.
- Rubik: present in the EvolutionX font pack; packaged variable version from [Google Fonts](https://fonts.google.com/specimen/Rubik), [source](https://github.com/google/fonts/tree/main/ofl/rubik). Variable wght 300–900.

Retrieved 2026-10-06. Google Fonts metadata and OFL notices are bundled alongside the font files. Lato uses its actual 400/500/600/700 faces; other families retain their variable axes. Inter uses optical size 32 for large clock digits.
