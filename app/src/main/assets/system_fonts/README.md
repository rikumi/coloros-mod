# System fonts

Unmodified upstream fonts. SIL Open Font License 1.1 notices are included next to the font files.
Inter and Manrope reuse the existing `../clock_fonts` assets and licenses.

## Sources

- Source Han Sans SC variable TTF: [Adobe release branch](https://github.com/adobe-fonts/source-han-sans/blob/release/Variable/TTF/SourceHanSansSC-VF.ttf), version 2.005. Full SC font, including traditional Chinese glyph coverage; the regional forms follow SC.
- Maple Mono regular and italic variable TTF: [official v7.9 release](https://github.com/subframe7536/maple-font/releases/tag/v7.9), `MapleMono-Variable.zip`.
- JetBrains Mono regular and italic variable TTF: [Google Fonts](https://github.com/google/fonts/tree/main/ofl/jetbrainsmono).
- Fira Code variable TTF: [Google Fonts](https://github.com/google/fonts/tree/main/ofl/firacode).
- Cascadia Code regular and italic variable TTF: [Microsoft v2407.24 release](https://github.com/microsoft/cascadia-code/releases/tag/v2407.24), `ttf/CascadiaCode.ttf` and `ttf/CascadiaCodeItalic.ttf`.

Retrieved 2026-10-22. Renamed for stable asset paths; font contents are unchanged.
