# 安装器设置

入口为系统净化 → 安装器。“旧版”指系统保留的 com.android.packageinstaller，区别于 com.oplus.appdetail。

恢复旧版安装器是独立 root 操作，不参与一键开启。开启时停用 appdetail；关闭时恢复其安装和启用状态。操作校验 shell 退出状态并重新读取结果，失败时不显示成功。

packageinstaller 作用域提供三个默认关闭的独立选项：

- 停用病毒扫描：使 CHECK_APK_VIRUS 服务解析使用原生不可用分支，保留原生安装确认，不自动提交安装。
- 移除完成页建议：处理异步重新显示的建议和推荐区域，保留安装结果、打开/完成按钮及自动删除安装包选项。
- 首屏标题栏：复用安装器工具栏与返回箭头，仅保留返回按钮和高度占位，不设置标题；返回使用原生 onBackPressed。

安装器加入推荐作用域；已有用户需自行确认该作用域已选中。一次性入口使用完整首次设置读取，高频回调读取内存快照。
