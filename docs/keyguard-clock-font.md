# 默认锁屏时钟字体

提供字体、等宽数字、字间距与字重四项独立设置。字体包含系统默认、Inter、Manrope、Rubik、Lato；字间距范围为 −0.10～0.10em，步长 0.01em；字重支持跟随系统及 100～900。

默认使用 Inter、等宽数字、细体 300、−0.04em。一键开启采用相同预设，一键关闭恢复系统字体、系统字重并关闭等宽和字间距。

兼容原生 SingleClockView 及默认时钟插件 ClockTimeView。前者精确匹配数字与冒号控件，并检查系统默认主题；后者要求原生配置包为 com.oplus.keyguard.clock.base 且 clockStyle=0，并排除非系统解锁主题。日期、附加消息、双时钟及其它主题和风格化样式不替换。

在字体设置后和数字测量前重申配置，热重载时恢复旧视图并发现已有默认时钟。保存原生 typeface、letterSpacing、fontFeatureSettings，离开目标样式时恢复。

冒号按当前字体数字与冒号可见字形的中心差进行绘制补偿，不改变控件位置、布局高度及动画 translationY。使用系统字体及字重或离开默认样式时不进行补偿。
