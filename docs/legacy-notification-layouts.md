# 通知布局

整数设置 notification_layout_style 提供 0 默认、1 旧版、2 宽松。初始值与一键开启均为 2，一键关闭为 0；不迁移旧设置键。模式切换在主线程清理旧状态并重新绑定已有通知。

## 旧版模板与兼容

使用 Android 15 框架的原始编译 XML，归档于 legacy_framework_notifications_15.zip。提取脚本同时保留递归依赖、资源名称及默认尺寸；加载时映射当前系统同名资源，保留 dp/sp 单位，以真实 XmlBlock.Parser 解析。仅在 SystemUI 处理通知，不替换系统 framework 文件，也不直接加载旧系统的 Java 类。

普通、展开、会话、媒体、通话和分组模板共同映射。当前系统展开按钮内部要求 LinearLayout，因此保留当前版本的 notification_expand_button。厂商包装器若对旧模板父容器作出不匹配的 FrameLayout 参数假设，则仅跳过该专用定位分支。

旧版恢复完整头部，隐藏应用名称与时间之间的分隔点；展开箭头居左，操作按钮取消额外起始缩进。消息模板保留头像，同时移除多余容器留白。第三方完全自定义 RemoteViews 不强制替换。

## 分组与展开

分组使用连续子项坐标和真实折叠高度，移除新版专用复制层缩放和逐项延迟，保留原生生命周期及堆叠安全检查。展开时长为 360ms。头部与内容几何参见 legacy-group-header-padding.md。

展开头部显示无背景的独立应用名称；整组和子卡片按共同进度连续淡变，不另造主题颜色。模板变换期间保持箭头左对齐，并恢复按压缩放状态。

整组内容统一计算上下留白。展开后的每条子通知在模板内部增加上下内边距，测量高度同步增加；折叠单行模板不逐行累加。位置、固有高度和动画边界使用同一组数值，避免裁切与跳变。

## 宽松布局

标准通知使用当前系统带完整头部的外壳，图标始终顶部对齐。短内容不显示折叠按钮，有长内容时保留原生展开按钮和内容变换。完全自定义内容不强制替换。

分组继续采用当前系统的头部和动画，折叠态增加独立应用名称行并为正文留出空间。图标在固定容器内顶部对齐，时间与名称行对齐；第一条折叠正文不再为时间重复预留末端宽度。

分组上下内边距与正文副本、子项状态和高度边界共同计算，另固定增加 2dp 总垂直留白，独立于内边距开关。切换模式与热重载恢复原布局参数及观察器。

## 测试通知与验证

设置下方的“发送测试通知”通过 shell 身份调用系统通知命令，不申请模块通知权限。使用固定 tag；已有同类通知时不重复发送，查询失败时不盲目发布。标题以 ColorOS Mod 开头，展开正文仅保留一行。

独立模板测试检查归档、资源映射与依赖；LegacyGroupGeometryTest 检查不同展开进度的高度和位置。交互验证还应覆盖会话、分组、锁屏、动画与关闭恢复。
