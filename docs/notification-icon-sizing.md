# 状态栏单色通知图标尺寸与着色

单色模式下，绘制目标为原生 status_bar_icon_drawing_size 减去 1.5dp；单元宽度为原生 status_bar_icon_size_sp 减去 3dp，并以绘制框为最小宽度。布局宽度与实际图形分别计算，避免缩窄间距时意外改变图案比例。

绘制时按 Drawable 固有尺寸、CENTER_INSIDE 拟合比例及原生 mIconScale 计算补偿，再使用 Canvas.save/restore 归一到目标框。保留原生缩放字段及动画，不累计修改参数。图标重新绑定时主动 invalidate；关闭功能恢复原始布局和绘制方式。

仅对实际替换成功的单色通知图标强制使用原生前景色路径，保留颜色插值、doze 与深浅色状态变化。保存最新原生可染色判断，关闭开关、视图复用及热重载时恢复。彩色图标及非通知系统图标不受影响。

末尾缺失通知计数共用绘制框和单元宽度，移除额外水平 margin；多位数字和 99+ 保留形状所需扩展。纯数字模式和隐藏模式沿用原生尺寸。密度变化重新读取资源，避免热重载后尺寸约束丢失。
