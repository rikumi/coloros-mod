# 修复系统通知应用名及合并显示

独立开关 notification_real_app_name_enabled 默认关闭，参与一键开关管理。开启时，系统应用及更新后的系统应用通知使用当前语言的真实应用名称，例如将系统界面的功能替代名称恢复为“系统界面”。普通第三方应用不改变。

仅在 SystemUI 覆盖框架和厂商的头部应用名显示路径，并更新已有头部视图；不修改原始 Notification 和 extras。关闭后重新绑定，恢复原生替代名称。

## Android 系统统一分组

通过原生 NotificationForceGroupEx 为同用户的 android 通知维护本地摘要。USER_ALL 通知归入当前用户，工作资料与个人用户分开。摘要进入完整绑定生命周期，不向系统服务发布额外通知；排名对账时临时排除本地摘要，避免被错误撤销。

关闭开关、真实子通知少于两条或热重载清理时释放摘要并重建列表。批量清除转换为可清除真实子通知并按 key 去重，不将虚拟 key 发送给系统服务，不清除常驻通知。

合并头部统一使用 stat_sys_adb 单色图案，数字圆圈采用半透明黑色背景和白色数字。分组变更仅对受本设置控制的系统通知绕过原生稳定性限制。状态栏仍按真实子通知的原生显示资格过滤，不强制显示应当隐藏的通知。
