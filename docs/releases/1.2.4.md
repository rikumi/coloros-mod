## 新增功能

- 新增系统中文、西文和等宽字体选择，提供思源黑体、Inter、Manrope、Maple Mono、JetBrains Mono、Fira Code 和 Cascadia Code。
- 支持分别导入自定义 TTC、TTF 和 OTF 字体，按字重和斜体选择字体集成员；重新导入覆盖该项上次保存的字体。
- 新增通过 LSPosed 注入的原生字体读取适配，无需配套 KernelSU 模块。Chrome 和使用 WebView 的应用需要加入作用域；独立渲染进程的兼容性仍待设备验证。
- 自定义等宽字体增加实际字符宽度检查，并阻止 ColorOS 将等宽字体再次替换为比例字体。

## 体验优化

- 系统字体页面增加专用入口图标，并提示修改字体后需重启 Zygote 生效。
- 长形磁贴圆角比例的可调范围扩展为 20%～50%，默认值保持 25%。

## 小修复

- 修正合并控制中心竖屏下磁贴图标放大可能被资源更新、布局或展开过程覆盖的问题。
- 修正上滑进入最近任务、尚未松手时背景遮罩仍可能出现的问题，覆盖桌面和应用内手势，并处理手势取消后的背景恢复。
