## 1.4.0 更新说明

### 主要更新

- 新增“替换关于本机卡片”，支持 ColorOS 17、16.1、16、15，OxygenOS 16、15，realmeUI 7、6，以及 ColorOS Mod。采用对应系统的原厂背景与布局，版本号和品牌始终根据真实信息显示；模块首页背景同步切换。
- 新增“系统 Emoji 字体”，支持默认、Apple、JoyPixels、Twitter、Samsung。字体按需下载并缓存，下载时显示“正在下载 Emoji 字体…”提示，就绪后提示重启 Zygote；优先使用 Emoji 字形，避免被文字字体覆盖。
- 新增“关闭系统字体替换”，修复 Telegram 等应用调用等宽字体时被系统替换的问题，无需增加第三方应用作用域。
- 新增“全进程挂载字体配置（试验性）”，使设置的字体对 WebView、Chrome 等网页渲染进程生效。该功能需 root 授权，默认关闭，一键启用也不会开启。

### 新增功能

- 新增“关于本机精简并隐藏营销用语”：隐藏电池和影像系统营销名称、移除性能平台，将充电参数整理为有线与无线功率，屏幕仅保留尺寸。
- 新增“系统级应用图标包图标”和“修复桌面图标包清晰度”，集中放在桌面的“图标包”分组。系统级图标替换排除桌面；桌面清晰度修复同时覆盖未适配图标的遮罩合成，放大时采用双立方采样。
- 新增“通知中心单色图标”和“修复设置已停用模块上下间距”，应用导航栏沉浸设置增加独立应用列表入口。
- 停用应用页面增加系统应用选择、操作风险确认及用途和依赖关系说明，区分可卸载、不建议卸载、卸载后自动恢复及系统不允许卸载等状态。
- 系统等宽字体增加“默认”选项。

### 体验优化

- 关于本机卡片根据实际系统版本、品牌与地区选择背景，区分 OxygenOS 与海外 ColorOS；ColorOS 16.0.7 及以上自动采用金色背景。realmeUI 使用对应的 6.0、7.0 版本显示，保留设备原厂品牌标识。
- 缺少或未启用软件更新应用时，仍显示完整的关于本机卡片，隐藏版本箭头并显示“已是最新版本”；恢复原厂内容排列，调整 OxygenOS 15、realmeUI 6 等样式的高度及文字位置。
- 精简关于本机参数的多余间距和换行，电池容量保持垂直居中；摄像头按后置、前置顺序显示，以 MP 表示像素，相邻相同参数的镜头合并为乘法形式，软件版本中的换行替换为空格。
- 桌面仅在每次 Zygote 启动后的首次加载补充刷新，后续重新启动桌面不再立即执行重复刷新；需要延后的刷新等待桌面稳定闲置，减少返回主屏幕时的干扰。
- 中文选择思源黑体时直接使用系统已有字体，减少 APK 体积；西文和等宽字体直接内置，Emoji 保留按需下载。
- 移除 Sender ID 功能及不再需要的作用域，统一相关设置名称与四种语言文案。

### 小修复

- 修复开启合并控制中心比例缩放后，手机横屏时字体与控件过大、整体位置偏下的问题；显示播放控件时隐藏顶部日期和工具栏，调整上下留白，使四行磁贴完整显示。
- 修复宽松消息通知在折叠、展开和弹出状态下的图标尺寸、应用名称缩进及头像显示，弹出通知保留头像，应用图标缩小置于顶部。
- 修复桌面图标与名称间距需要点击图标才生效的问题，修改后直接更新已显示图标。
- 修复模块首页背景加载后跳动的问题，背景在素材和布局均准备就绪后显示。
- 修复字体下拉菜单外显值未及时更新、字体导入或保存失败，以及 JoyPixels、Samsung 的兼容性问题。
- 修复选择默认字体后未恢复 OPPO Sans 的路径，区分简繁体字形，并保留独立选择的西文字体；修复 WebView 字体挂载被 root 辅助进程的特殊命名空间阻断而回滚的问题。
- 修复扫描或应用字体配置期间，进程退出或切换命名空间引发的偶发失败；保留最近一次失败日志，避免被后续成功操作覆盖。
- 固定模块设置标题、副标题和下拉选项的文本测量高度与固有高度，避免随所选字体的额外留白改变行高。
